# 평행선 구하기

## 문제

점 네 개의 좌표를 담은 이차원 배열 dots가 다음과 같이 매개변수로 주어집니다.

[[x1, y1], [x2, y2], [x3, y3], [x4, y4]]
주어진 네 개의 점을 두 개씩 이었을 때, 두 직선이 평행이 되는 경우가 있으면 1을 없으면 0을 return 하도록 solution 함수를 완성해보세요.

## SUDO

1. 2개의 점을 짝을 지어 나올 수 있는 경우의 수 구하기
2. <span style="color:orange">**두 선의 기울기**</span> 구하기
3. 두 선의 기울기가 같다면 통과!

두 선의 기울기를 구하는 공식은 다음과 같다.\
점 A,B,C,D가 있을 때:

> $$기울기 = \frac{y2 - y1}{x2 - x1} = \frac{y \text{ 변화량}}{x \text{ 변화량}}$$

소수점 오차가 존재하므로 나누기 대신 비례식 계산 `내항의 곱 = 외항의 곱`을 사용

## CODE

```py
def solution(dots):
    a, b, c, d = dots

    # 모든 경우의 수
    c1 = [a,b,c,d]
    c2 = [a,c,b,d]
    c3 = [a,d,b,c]

    every_case = [c1, c2, c3]

    for p1,p2,p3,p4 in every_case:
        # 순회 중 하나라도 같은 게 있다면 return 1
        if (p2[1] - p1[1]) * (p4[0] - p3[0]) == (p2[0] - p1[0]) * (p4[1] - p3[1]):
            return 1
    # 모든 순회가 끝나고 같은게 없다면 return 0
    return 0
```

이걸 사용하면 나중에 차트에 평행채널을 그릴 수 있을거 같다.

# 유한소수 판별하기

## 문제

소수점 아래 숫자가 계속되지 않고 유한개인 소수를 유한소수라고 합니다. 분수를 소수로 고칠 때 유한소수로 나타낼 수 있는 분수인지 판별하려고 합니다. 유한소수가 되기 위한 분수의 조건은 다음과 같습니다.

- 기약분수로 나타내었을 때, 분모의 소인수가 2와 5만 존재해야 합니다.
  두 정수 a와 b가 매개변수로 주어질 때, a/b가 유한소수이면 1을, 무한소수라면 2를 return하도록 solution 함수를 완성해주세요.

## SUDO

기약분수 = 분자와 분모의 공약수가 1뿐이라 더 이상 약분할 수 없는 수

1. a는 분자, b는 분모
2. 두 수의 최대공약수를 구한다. (유클리드 호제법)
3. 최대 공약수로 분모를 나눈다.
4. b가 2 or 5 이면 유한소수, 아니면 무한소수

### 유클리드 호제법(최대공약수 구하기)

```py
def gcd(x,y):
    remainder = x % y
    if remainder == 0:
        return y
    else:
        return gcd(y, remainder)
```

위처럼 사용했는데 이 때, y = 0일 수 있어서 올바른 방식은 다음과 같다.

```py
def gcd(x, y):
    if y == 0:
        return x
    return gcd(y, x % y)
```

## CODE

```py
def gcd(x, y):
    if y == 0:
        return x
    return gcd(y, x % y)

def solution(a, b):
    g = gcd(a, b)
    b = b // g

    # 분모를 계속 나눠서 1이 남는지 확인
    while b % 2 == 0:
        b = b // 2

    while b % 5 == 0:
        b = b // 5

    # 1이면 분모의 소인수가 2,5밖에 없다는 것
    if b == 1:
        return 1
    else:
        return 2
```
